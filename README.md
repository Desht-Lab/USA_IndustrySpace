# Пространство отраслей США · CBP 2023

Статичная платформа DESHT: сеть близости 312 отраслей NAICS по 925 городским агломерациям США, методология и проверки. Все страницы работают без сервера, данные вшиты в html.

- `index.html` — сеть: SVG с фиксированной раскладкой, фильтр по городу, поиск, карточка отрасли, покраска по группам или кластерам Louvain
- `demo.html` — демо для широкой аудитории: нечёткий поиск отрасли по русскому или английскому названию, сложность 0–1, соседи по сети, тип городской экономики, города
- `data/network.js` — данные сети (узлы с русскими названиями, связи, города), общие для `index.html` и `demo.html`
- `clusters.html` — описательная статистика по кластерам Louvain: сводка, состав, PCI, связи, города
- `methods.html` — методология, примеры (523 ценные бумаги, 722511 рестораны), проверки, оговорки
- `assets/style.css` — общие стили, те же, что в «Пространство ОКЭД3» (Атырау)
- `nodes_312_naics6.txt` — координаты узлов, выгружены из pyvis-сети состояния 32 тыс.
- `_index_template.html`, `_demo_template.html` — шаблоны; страницы и `data/network.js` собираются скриптом `../build_platform.py`, русские названия из `../naics_ru.json`

Основное состояние: свёртка по порогу 32 тыс. занятых, RCA ≥ 1 по занятости, связь proximity × √sIDF ≥ 0,99 (тот же перцентиль, что proximity ≥ 0,5), 2 211 связей, 39 рёбер MST ниже порога пунктиром.
